## How to Deploy on GitHub Pages / Cómo Publicar en GitHub Pages

1. Push all files to your GitHub repository (including the `images/` directory with `sutin.webp`, `agwntdas.webp`, and `modelo1.png` to `modelo4.png`).
2. On GitHub, navigate to: **Settings** -> **Pages**.
3. Under **Branch**, select `main` (or `master`) and `/ (root)`. Click **Save**.
4. In about 60 seconds, your portfolio will be live at:  
   `https://your-username.github.io/your-repository/`
